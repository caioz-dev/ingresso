# 🎟️ Ingresso

Aplicação web para simular a compra de ingressos, com seleção 
de tipo e quantidade respeitando o estoque disponível.

## 🚀 Funcionalidades

- Escolha do tipo de ingresso
- Seleção de quantidade com validação de estoque
- Controle de disponibilidade em tempo real

## 🛠️ Tecnologias

- HTML5 · CSS3 · JavaScript
